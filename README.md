# teiko-clinical-trial-analysis
Teiko Technical Assessment -- Immune Cell Population Analysis on Clinical Trial Data

## Starter SQLite setup

This repository now includes:

- `schema.sql`: starter schema for clinical trial observation data
- `clinical_trial_data.csv`: starter dataset to load
- `load_data.py`: script to initialize a SQLite `.db` file and load data

Run:

```bash
python load_data.py
```

This creates `clinical_trial.db` in the repository root.
